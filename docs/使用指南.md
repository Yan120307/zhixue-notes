# 智学笔记使用指南

## 一、怎么打开平台（3 种方式）

### 方式一：一键启动（推荐）
双击仓库目录下的 **`start.bat`**，自动完成：
1. 检查并安装依赖（仅首次）
2. 启动后端服务（端口 8766）
3. 启动前端服务（端口 8765）
4. 自动打开浏览器

### 方式二：手动启动（两条命令）
打开 PowerShell，执行：
```powershell
# 窗口 1：启动后端
cd zhixue-notes\backend
python server.py

# 窗口 2：启动前端
cd zhixue-notes\frontend
python -m http.server 8765
```
浏览器打开 http://127.0.0.1:8765

### 方式三：Docker 一键部署（服务器/长期使用）
```bash
docker compose up -d
# 浏览器打开 http://localhost:8765
```

## 二、启用 AI 增强（可选）

不配置也能用（基础提炼），配置后每个知识点自动生成通俗解释：

```powershell
# PowerShell 临时设置（本次窗口有效）
$env:DASHSCOPE_API_KEY = "sk-你的Key"
python backend\server.py
```

永久设置：系统设置 → 高级系统设置 → 环境变量 → 新建 `DASHSCOPE_API_KEY`。
API Key 免费获取：https://bailian.console.aliyun.com/ → API-KEY 管理

## 三、日常使用

1. 浏览器打开平台 → 粘贴资源链接（B站视频/网盘/网页/文本）
2. 点击「一键整理」
3. 笔记卡片展开 → 下载 md/pdf/思维导图，或点「在线预览」

## 四、停止服务

关闭两个最小化的 Python 黑窗口，或任务管理器结束 python 进程。
