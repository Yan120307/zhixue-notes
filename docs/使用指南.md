# 智学笔记 · 使用手册

> 粘贴任意学习资源（链接 / 文本 / 视频 / 音频文件），一键生成结构化重点笔记（Markdown / PDF / 思维导图 / Anki 卡片）

---

## 一、启动平台

### 方式一：Windows 一键启动（推荐）

双击仓库根目录的 **`start.bat`**，自动完成：
1. 定位可用 Python（py 启动器 → python/python3 → 常见安装路径；也可用环境变量 `ZHIXUE_PYTHON` 指定 python.exe 完整路径，适合便携版/嵌入式 Python）
2. 首次运行自动安装依赖
3. 启动前后端服务，自动打开浏览器

> 重复双击无害：已在运行的服务会自动跳过。

### 方式二：Docker 一键部署

```bash
docker compose up -d
# 浏览器打开 http://localhost:8765
```

### 方式三：手动启动（全平台）

```bash
pip install -r requirements.txt
cd backend && python server.py        # 窗口 1：后端（端口 8766）
cd frontend && python -m http.server 8765   # 窗口 2：前端
# 浏览器打开 http://127.0.0.1:8765
```

## 二、支持的资源类型

| 类型 | 输入方式 | 处理方式 |
|---|---|---|
| **网页文章** | 粘贴任意网址 | 自动抓取正文（剔除导航/广告/评论噪声），按内容分章提炼 |
| **B站视频（有 CC 字幕）** | 粘贴视频链接 | 直接抓取官方字幕，按时间轴分章 |
| **B站视频（无 CC 字幕）** | 粘贴视频链接 | **弹窗征求同意后**：下载音频 → 本地转写（不上传任何内容）→ 笔记生成后自动删除音频 |
| **本地视频/音频文件** | 拖入页面任意位置，或点击「选择文件」按钮 | 上传 → 确认弹窗 → 本地转写 → 笔记（转写后自动删除上传的源文件） |
| **纯文本/讲义/文稿** | 直接粘贴大段文字 | 按句分条、按内容分章提炼 |
| **网盘分享链接** | 粘贴链接或含链接的分享消息 | 自动识别并给出操作引导（见 FAQ） |

> **任意链接都能识别**：含链接的混合文本（如网盘分享消息、视频转发文案）会自动提取其中的链接并分类处理。

## 三、整理流程与进度

1. 粘贴资源 / 拖入文件
2. 点击「一键整理」（或拖入文件后自动开始）
3. 观察进度条：总进度百分比 + 四步指示（解析资源 → 获取内容 → 提炼重点 → 生成笔记）+ 实时耗时
4. 完成后笔记卡片出现在「我的笔记」，展开即可下载全部文件

**转写确认弹窗**（无字幕视频/本地文件）会说明：
- 音频体积与预计耗时（约为视频时长的 1/3）
- 全程本地处理，不上传任何内容
- 生成后自动删除媒体文件

点「下载并转写」继续，点「取消」终止任务。

## 四、交付物

| 文件 | 说明 |
|---|---|
| `notes.md` | 结构化笔记（概述 / 章节要点 / 原文摘录 / 考点清单） |
| `笔记.pdf` | 中文友好排版，可直接打印 |
| `思维导图.png` | 知识图谱横向树，按章节配色 |
| `Anki卡片.txt` | TSV 制卡，导入 Anki 即可间隔记忆 |
| `knowledge_map.json` | 结构化知识图谱（可编程处理） |

> 笔记卡片上还有「导出 Anki」（按需补生成）和「写入 Obsidian」（同步到你的知识库）按钮。

### Anki 导入方法

Anki → 文件 → 导入 → 选择 `Anki卡片.txt`（TSV 格式），字段分隔选 Tab，完成。

### Obsidian 集成

设置页「Obsidian 集成」填入 Vault 本地路径（如 `D:\MyVault`）→ 笔记卡片点「写入 Obsidian」，笔记与 MOC 索引页写入 `ZhixueNotes/` 目录。

## 七、数据存储

- 笔记任务数据：`~/.zhixue-notes/tasks/`（用户主目录，跨平台）
- 前端浏览记录：浏览器 localStorage（本机）
- 转写媒体文件：笔记生成后**自动删除**，不留任何视频/音频
- 转写文本（transcript.srt）保留，同一视频重复整理秒级完成

## 八、常见问题（FAQ）

**Q1：B站视频提示「无 CC 字幕且本地转写失败：ConnectError」**
早期版本加载转写模型时会联网检查更新，网络抖动即失败。**新版已改为离线优先加载**（模型缓存在本地时不再联网）。若首次使用未下载过模型，需保证网络可用一次以完成下载。

**Q2：校园网盘链接（如西农网盘）无法自动整理**
部分校园网盘仅校园网/特定 DNS 可达，且分享页结构各异，自动下载客观不可行。**推荐路径**：在网盘下载视频文件 → 拖入本平台 → 自动转写整理（这条通道不依赖任何网盘接口）。

**Q3：B站大部分教学视频没有 CC 字幕？**
是的，B站字幕需 UP 主上传，教学长视频大多没有。本平台内置本地转写（faster-whisper）作为兜底，无字幕视频同样可整理，准确率为 small 模型水平，高频教学术语已内置自动校正。

**Q4：双击 start.bat 提示未找到 Python**
安装 [Python 3.8+](https://www.python.org/downloads/)（勾选 Add to PATH）后重试；或设置环境变量 `ZHIXUE_PYTHON` 指向已有 python.exe。

**Q5：整理失败提示「依赖安装失败」**
检查网络后重新双击 start.bat；或手动执行 `pip install requests reportlab matplotlib`。

**Q6：端口被占用（8765/8766）**
平台已在运行时重复双击会自动跳过；如需彻底重启，任务管理器结束 python 进程后重新双击 start.bat。

**Q7：转写要多久？**
约为视频时长的 1/3（CPU small 模型实测：15 分钟视频约 5 分钟）。进度条实时显示百分比与预计剩余时间。转写期间可关闭窗口挂后台，切勿关机。

**Q8：上传的文件安全吗？**
全程本地处理：文件保存在本机 `~/.zhixue-notes/tasks/`，转写在本机运行，**绝不上传到任何服务器**；笔记生成后源文件自动删除。
