## 一、五分钟上手

### 第 1 步：启动

选一种，**新手推荐第一种**。

| 方式 | 操作 | 适合 |
|---|---|---|
| **Windows 一键启动** | 双击仓库根目录的 `start.bat` | Windows 用户（推荐） |
| **Docker** | `docker compose up -d`，打开 `http://localhost:8765` | 已装 Docker |
| **手动启动** | 见下方命令 | 其他系统 / 需要自定义 |

手动启动（全平台）：

```bash
pip install -r requirements.txt

# 窗口 1：后端（端口 8766）
cd backend && python server.py

# 窗口 2：前端（端口 8765）
cd frontend && python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

> Windows 上 `start.bat` 会自动探测 Python、首次运行自动装依赖、启动前后端并打开浏览器。
> 重复双击无害（已在运行的服务会自动跳过）。便携版 Python 可用环境变量 `ZHIXUE_PYTHON` 指定解释器路径。

### 第 2 步：粘贴内容

在主页输入框粘贴**任意**下列内容，然后点「一键整理」：

- 视频链接（B 站 / YouTube，短链、手机版链接、多 P 链接都能认）
- 网页文章链接（会自动剔除导航、广告、评论）
- PDF / Word / txt 直链
- 网盘分享链接（会识别并给出可操作建议）
- 一整段讲义、字幕文稿、笔记文本

也可以**直接把视频/音频文件拖到页面上**（支持 mp4 / mkv / mov / mp3 / wav 等）。

### 第 3 步：拿结果

整理完成后，笔记卡片出现在「我的笔记」，展开即可下载全部文件。
点笔记标题可以**在线预览**，不用下载就能读。

> **只想快速看效果？** 随便找一篇技术文章链接粘进去，10 秒左右就能出一份笔记。

## 二、接入 AI 大模型（强烈建议）

### 为什么建议接

不接大模型也能用，但两者的区别是**质变**：

| | 不接大模型 | 接了 AI 大模型 |
|---|---|---|
| 章节划分 | 按固定时长切（每 5 分钟一章） | 按**内容主题**划分，章节标题是真正的主题名 |
| 知识点标题 | 从原文提炼名词短语 | 模型生成准确的概念名，如「WBI 签名的生成流程」 |
| 知识点说明 | 原文句子拼接 | 模型重写成通顺的解释 |
| 一句话掌握 | 无 | 有 |
| 通俗解释 | 无 | 有（生活化类比） |
| 必背考点 | 无 | 有（5~8 条） |

### 怎么接（60 秒，不用改环境变量、不用重启）

1. 打开平台 → 左下角「设置」→ 找到 **「AI 大模型」** 区块
2. 「服务商」下拉，选一个（下面有对比）
3. 「API Key」粘贴你的 Key（去提示的网址申请，点一下就能打开）
4. 「模型」会自动填好，通常不用改
5. 点 **「保存并测试」** → 显示「✅ 配置成功！」即可，**立刻生效，无需重启**

配置保存在本机 `~/.zhixue-notes/config.json`，Key 不会上传到任何地方。

### 服务商怎么选

| 服务商 | 费用 | 是否推荐 | 说明 |
|---|---|---|---|
| **硅基流动 SiliconFlow** | 送免费额度，部分模型长期免费 | ⭐ 国内首选 | 国内直连，注册即用 |
| **Ollama（本地）** | **完全免费** | ⭐ 隐私优先 | 装 Ollama 后 `ollama pull qwen2.5:7b`，数据不出本机、无需 Key |
| **智谱 GLM** | `glm-4-flash` 免费档 | ⭐ 想白嫖选这个 | 中文教学场景表现不错 |
| **魔搭 ModelScope** | 每日免费额度 | 可以 | 绑定阿里云账号 |
| **阿里云百炼（通义千问）** | 新用户免费额度 | 可以 | 老版本用户可继续用 |
| **DeepSeek 官方** | 付费，价格低 | 质量好 | 中文总结质量突出 |
| **OpenRouter** | `:free` 后缀模型免费 | 需境外网络 | 有速率限制 |
| **OpenAI** | 付费 | 需境外网络 | — |
| **自定义** | — | — | 任何 OpenAI 兼容接口：填 Base URL + Key + 模型名 |

> **完全不想花钱、也不想注册？** 装 [Ollama](https://ollama.com/download)，
> 执行 `ollama pull qwen2.5:7b`，然后在设置里选「Ollama（本地模型）」，
> API Key 留空，点保存即可。首次拉模型约 4.7GB，之后永久离线可用。

### 「提炼强度」是什么

| 档位 | 做什么 | 适合 |
|---|---|---|
| 快速 | 分章 + 提炼知识点 | 想快点出结果、文稿很长 |
| **标准（默认）** | 加「一句话掌握 + 通俗解释」 | 大多数情况 |
| 深度 | 再加「易错点/易混淆点」 | 备考、需要吃透概念 |

### 旧方式仍然可用（环境变量）

老用户配置的环境变量依然生效，**优先级低于**网页设置：

```bash
export DASHSCOPE_API_KEY=sk-你的Key     # Linux/macOS
set DASHSCOPE_API_KEY=sk-你的Key         # Windows CMD
$env:DASHSCOPE_API_KEY="sk-你的Key"      # Windows PowerShell
```

也支持 `ZHIXUE_LLM_API_KEY` / `ZHIXUE_LLM_BASE_URL` / `ZHIXUE_LLM_MODEL` 通用变量。
环境变量适合 Docker 部署与命令行使用；**日常使用建议用网页设置**，改了立刻生效。

## 三、支持的资源类型

| 类型 | 输入方式 | 处理方式 | 需要额外安装 |
|---|---|---|---|
| **B 站视频（有字幕）** | 粘贴链接 | 抓官方/CC 字幕，按时间轴分章 | — |
| **B 站视频（无字幕）** | 粘贴链接 | 弹窗同意后：下载音频 → 本地转写 → 删音频 | `faster-whisper` |
| **B 站短链 / 手机版 / 多 P** | 粘贴任意形式链接 | 自动跟随跳转解析；`?p=5` 会抓第 5 P | — |
| **YouTube 视频** | 粘贴链接 | 抓自动/人工字幕 | `yt-dlp`（建议） |
| **网页文章** | 粘贴任意网址 | 抓正文，剔除导航/广告；失败时用公共阅读器兜底 | — |
| **PDF / Word / txt 直链** | 粘贴文档链接 | 下载并抽取文字后整理 | PDF 需 `pypdf` |
| **纯文本 / 讲义 / 文稿** | 直接粘贴大段文字 | 按句分条、按内容分章 | — |
| **本地音视频文件** | 拖到页面或点「选择文件」 | 上传 → 确认 → 本地转写 → 删源文件 | `faster-whisper` |
| **网盘分享链接** | 粘贴链接或含链接的分享消息 | 识别并给出操作引导（见 FAQ Q2） | — |

> **链接容错说明**：含链接的混合文本（网盘分享消息、视频转发文案）会自动提取其中的链接；
> 各种短链、带跟踪参数的链接、手机版链接都能识别。
> 万一某个链接确实抓不到，程序会明确告诉你**原因**和**下一步怎么做**，不会默默失败。

## 四、整理流程与进度

1. 粘贴资源 / 拖入文件
2. 点「一键整理」（拖入文件会自动开始）
3. 看进度条：**总进度百分比 + 四步指示 + 实时日志 + 耗时**

四个阶段：

```
① 解析资源  →  ② 获取内容  →  ③ 提炼重点  →  ④ 生成笔记
```

- **② 获取内容**最耗时：无字幕视频要下载音频 + 本地转写（约为视频时长的 1/3）
- **③ 提炼重点**：接入大模型时，这里会逐段调用模型，长视频会有多次请求
- 期间可以关掉浏览器窗口挂后台，但**不要关机**

### 转写确认弹窗

无字幕视频或本地文件会先弹窗，说明：

- 音频体积与预计耗时
- 全程本地处理，**不上传任何内容**
- 生成后自动删除媒体文件

点「下载并转写」继续，点「取消」终止任务。

## 五、交付物说明

| 文件 | 内容 |
|---|---|
| `notes.md` | 结构化笔记：概述 → 核心知识图谱 → 分章要点（含原文摘录、一句话掌握、通俗解释）→ 考点清单 |
| `笔记.pdf` | 中文友好排版，内嵌视频关键画面，可直接打印 |
| `思维导图.png` | 知识图谱横向树，按章节配色 |
| `Anki卡片.txt` | TSV 制卡，导入 Anki 即开始间隔重复 |
| `knowledge_map.json` | 结构化知识图谱，便于二次开发 |
| `screenshots/` | 视频重点画面截图（装了 playwright 才有） |

笔记正文里每个知识点包含：

- **核心要点**：这个知识点讲了什么
- **原文摘录**：来自原始内容的对应片段（方便核对，不会编造）
- **一句话掌握 / 通俗解释**：接入大模型后才有

## 六、可选增强组件

```bash
# ① 无字幕视频本地转写（B站大量教学视频无 CC 字幕，强烈建议装）
pip install faster-whisper

# ② PDF 直链解析（纯 Python，装卸都很快）
pip install pypdf

# ③ YouTube 字幕抓取
pip install yt-dlp

# ④ 视频关键帧截图 / 网盘文件浏览
pip install playwright && playwright install chromium
```

**不装也能用**：缺失的组件会让对应功能走「明确提示 + 替代方案」的分支，其他功能完全不受影响。

### 转写模型的精度与速度

| 模型 | 大小 | 速度 | 精度 | 建议 |
|---|---|---|---|---|
| `tiny` | ~75MB | 最快 | 差 | 只做试跑 |
| `base` | ~145MB | 快 | 一般 | — |
| **`small`（默认）** | ~500MB | 中 | 较好 | 日常够用 |
| `medium` | ~1.5GB | 慢 | 好 | 课程术语多时更准 |
| `large-v3` | ~3GB | 很慢 | 最好 | 有 GPU 再考虑 |

改默认模型：编辑 `~/.zhixue-notes/config.json` 里的 `transcribe.model`。
转写已完成的内容会缓存（`transcript.srt`），同一视频再次整理是秒级完成。

## 八、数据与隐私

| 数据 | 位置 | 说明 |
|---|---|---|
| 笔记与任务 | `~/.zhixue-notes/tasks/<任务ID>/` | 全部在本机 |
| 配置（含 API Key） | `~/.zhixue-notes/config.json` | 只在本机，权限由系统保护 |
| 错误日志 | `~/.zhixue-notes/llm-error.log` | 大模型调用失败时的记录 |
| 前端浏览记录 | 浏览器 localStorage | 清除浏览器数据会丢失，可在设置里导出备份 |
| 转写的音频/视频 | **笔记生成后自动删除** | 不留任何媒体文件 |
| 转写文本 | `transcript.srt` 保留 | 便于重复整理时秒级完成 |

### 联网行为说明

为了透明，这里列出**会联网**的操作：

| 操作 | 联网去向 | 能否关闭 |
|---|---|---|
| 抓取视频字幕 / 网页正文 / 下载文档 | 对应网站本身 | 不联网就没法抓，属必需 |
| **公共阅读器兜底**（网页抓不到时） | `r.jina.ai`（第三方） | ✅ 可关：设置里把 `network.reader_fallback` 改为 `false` |
| **AI 通俗解释 / 考点提炼** | 你选的大模型服务商 | ✅ 可关：设置页点「关闭 AI」 |
| 本地转写（faster-whisper） | **不联网**（首次下模型除外） | — |

> **对隐私要求高？** 用 Ollama 本地模型 + 关掉阅读器兜底，整个流程完全不出本机。

## 九、常见问题 FAQ

**Q1：B 站视频提示「无字幕且本地转写失败」？**
先看失败原因：

- `ConnectError` / 网络相关 → 早期版本加载模型时会联网检查更新。**新版已改为离线优先**（模型有缓存时不联网）。首次使用需联网一次下载模型。
- 提示未安装 faster-whisper → 执行 `pip install faster-whisper`
- 提示音频下载失败 → B 站 CDN 偶发抖动，重新整理一次即可；已下载的分块会**断点续传**

**Q2：网盘链接（含校园网盘）无法自动整理？**
网盘分享页结构各异，且部分校园网盘仅校园网可达，自动下载客观不可行。**推荐路径**：
在网盘下载视频文件 → 拖入本平台 → 自动转写整理。这条通道不依赖任何网盘接口。

**Q3：B 站大部分教学视频没有 CC 字幕？**
是的，B 站字幕需 UP 主上传。本平台内置本地转写作为兜底，无字幕视频同样能整理。
转写质量取决于模型档位（见 [第六章](#六可选增强组件) 的模型对比表）。
若你有视频文稿，直接粘贴到输入框效果最好。

**Q4：多 P 视频（合集）只整理了第一 P？**
现已支持：链接里带 `?p=5` 就会整理第 5 P。默认整理第 1 P。
进度日志里会显示「第 5/12 P」。

**Q5：AI 配置保存后不生效？**
点「保存并测试」，看提示：

- 「✅ 配置成功」→ 已生效，下次整理即用
- 「⚠️ 已保存，但连接测试未通过」→ 常见原因：Key 错、Base URL 错、没网、额度用完。
  错误详情会写入 `~/.zhixue-notes/llm-error.log`

**Q6：报告「未配置大模型，使用基础提炼」但明明配了？**
网页设置里的开关可能被关了。设置页点一次「保存并测试」即可重新启用；
或检查是否把 Key 误填成了打码值（如 `sk-abc...wxyz`）。

**Q7：双击 start.bat 提示未找到 Python？**
安装 [Python 3.8+](https://www.python.org/downloads/)（勾选 Add to PATH）后重试；
或设置环境变量 `ZHIXUE_PYTHON` 指向已有 python.exe。

**Q8：端口被占用（8765 / 8766）？**
重复双击会自动跳过已在运行的服务。需彻底重启：任务管理器结束 python 进程后重新双击。

**Q9：转写要多久？**
约为视频时长的 1/3（CPU + small 模型：15 分钟视频约 5 分钟）。
进度条实时显示百分比与预计剩余时间。装了 GPU 版 PyTorch 会明显更快。

**Q10：上传的文件安全吗？**
文件保存在本机 `~/.zhixue-notes/tasks/`，转写在本机运行，**绝不上传到任何服务器**；
笔记生成后源文件自动删除。

**Q11：整理失败后列表里出现空壳笔记？**
不会。内容不足或抓取失败时会**明确说明失败原因**，不会生成空笔记（这是早期版本的问题，已修复）。

**Q12：重启服务后之前的笔记还在吗？**
在。笔记文件一直在磁盘上，笔记列表会从磁盘重建，不会因为重启而消失。

## 十、故障排查速查表

| 现象 | 最可能原因 | 怎么办 |
|---|---|---|
| 页面能开，点整理没反应 | 后端没启动 | 启动 `backend/server.py`，确认 8766 端口在监听 |
| 「无法连接本地服务」 | 后端挂了 / 端口被占 | 看后端窗口的报错；换端口 `python server.py --port 8767`（前端同步改 API 地址） |
| 提示缺少 requests / reportlab | 依赖没装全 | `pip install -r requirements.txt` |
| 字幕抓取失败 | 视频无字幕 / 需要登录 / 链接是结果页 | 用播放页链接；无字幕视频装 faster-whisper |
| 网页抓不到正文 | JS 渲染页面 / 反爬 | 开启阅读器兜底（默认开）；或复制网页文字粘贴 |
| PDF 提示解析失败 | 未装 pypdf / 扫描版 PDF | `pip install pypdf`；扫描版需先 OCR |
| 思维导图/PDF 没生成 | 缺少 matplotlib / reportlab | 看后端日志里的 `export_pdf ok=...` / `gen_mindmap ok=...` |
| 大模型一直失败 | Key/额度/网络 | 设置页点「仅测试连接」看具体报错 |
| 转写很慢 | CPU + small 模型 | 属正常；可换 tiny 模型，或装 GPU 版 PyTorch |
| 中文乱码 | 控制台编码 | 属显示问题，文件内容正常；可 `chcp 65001` |

**看日志**：`~/.zhixue-notes/zhixue-backend.log`（服务日志）与 `llm-error.log`（模型调用）。

## 十一、部署方式

### Docker（推荐给服务器 / 群晖等）

```bash
docker compose up -d
# 打开 http://localhost:8765
```

数据目录挂载在容器外，重建容器不丢笔记。
Docker 里配置大模型建议用**环境变量**（容器内不方便点网页设置）：

```yaml
environment:
  - DASHSCOPE_API_KEY=sk-你的Key
```

### 手动部署
