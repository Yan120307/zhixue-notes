## 二、上线方案对比

### 方案 A：正式网站（SaaS）

| 维度 | 评估 |
|---|---|
| 可行性 | 中等。需要后端服务器+域名+HTTPS，字幕抓取依赖 B站/YouTube API（可能被反爬），LLM 提炼需接入大模型 API（成本） |
| 核心改造 | ① 前端部署到 CDN/静态托管；② 后端从 localhost 改为云服务器（FastAPI/Flask）；③ 字幕抓取加代理池或官方 API 授权；④ LLM 提炼接入 OpenAI/通义千问 API |
| 成本 | 服务器 ~50-200元/月（2C4G）；LLM API ~0.01-0.05元/次（按 token）；域名+HTTPS ~100元/年 |
| 优势 | 用户无需安装任何东西，浏览器打开即用；可规模化 |
| 劣势 | 需持续运维；字幕抓取可能被平台封禁；LLM 调用成本随用户增长；隐私问题（用户内容上传云端） |
| 合规 | B站/YouTube 字幕抓取需确认各平台机器人协议；用户上传内容需隐私声明 |

### 方案 B：微信小程序

| 维度 | 评估 |
|---|---|
| 可行性 | 较高。小程序生态成熟，但受限于微信平台规则 |
| 核心改造 | ① 前端用小程序框架重写（WXML/WXSS/JS）；② 后端同方案 A 需云服务器或微信云开发；③ 视频截图功能需后端 Playwright（小程序端无法直接操作浏览器） |
| 成本 | 微信云开发基础版免费（有限额）；超出后 ~20-50元/月；LLM API 同上 |
| 优势 | 触达微信 12 亿用户；社交分享天然便利；扫码即用 |
| 劣势 | 小程序无法直接运行 Python/Playwright；所有能力需后端 API 化；审核周期 1-7 天；包大小限制 2MB（主包） |
| 合规 | 小程序内容审核严格；教育类需相关资质；视频内容可能触发版权审核 |
| 推荐 | 适合作为轻量入口（粘贴链接→云端整理→小程序查看笔记），完整能力仍需后端支撑 |

### 方案 C：GitHub 开源（推荐首选）

| 维度 | 评估 |
|---|---|
| 可行性 | 高。当前架构天然适合开源：纯前端 HTML + Python 后端 + 技能脚本 |
| 核心改造 | ① 整理目录结构（前端/后端/脚本/文档）；② 写 README（安装+使用+截图）；③ 加 LICENSE（MIT）；④ 加 `.gitignore`（排除 __pycache__/.pyc/.temp） |
| 成本 | 免费（GitHub 公开仓库） |
| 优势 | 零成本；社区贡献可持续；用户本地运行隐私安全；与 TeleAgent 技能生态天然衔接 |
| 劣势 | 需用户有 Python 环境；非技术用户门槛较高 |
| 合规 | 开源无合规风险；注意脚本中不含任何硬编码密钥 |
| 推荐 | **最推荐**。当前代码已具备开源质量（验证通过+安全扫描无风险+文档完善） |

### 方案 D：Electron 桌面应用

| 维度 | 评估 |
|---|---|
| 可行性 | 中等。可将 HTML + Python 后端打包为桌面应用 |
| 核心改造 | ① Electron 封装前端；② Python 后端打包为 exe（PyInstaller）；③ 安装包分发 |
| 成本 | 打包工具免费；分发可通过 GitHub Releases |
| 优势 | 双击即用，无需配置 Python；本地运行隐私好 |
| 劣势 | 安装包较大（~150MB，含 Python+库）；需维护多平台构建（Windows/Mac/Linux） |
| 推荐 | 适合后续作为「给非技术用户的发行版」 |

## 三、推荐上线路径（分阶段）

### 第一阶段：GitHub 开源（立即可做，零成本）
1. 整理仓库结构：`/frontend`（平台 HTML）、`/backend`（server.py）、`/scripts`（技能脚本）、`/docs`（文档）
2. 写 README：功能介绍、安装步骤、使用截图、API 文档
3. 加 LICENSE（MIT）、`.gitignore`
4. 发布 GitHub Releases v1.0
5. 在 TeleAgent 社区/博客宣传

### 第二阶段：云端 SaaS（验证需求后）
1. 后端部署到云服务器（FastAPI + Nginx）
2. 前端部署到 CDN
3. LLM 提炼接入通义千问 API（国内合规）
4. 按量计费或免费限额

### 第三阶段：小程序入口（扩大触达）
1. 小程序做轻量入口（粘贴链接→云端整理→查看笔记）
2. 完整功能引导到 Web 版
