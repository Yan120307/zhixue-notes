功能说明 ▾

一键整理：主页粘贴任意学习资源（网课视频 / 网盘分享文件夹 / 网页文章 / PDF·Word 文档 / 文本内容），平台自动识别资源类型并整理成结构化重点笔记。

三种默认交付：Markdown 笔记、PDF 文档（内嵌重点画面）、思维导图图片，可在输入框下方按需勾选。

重点画面截图：视频类资源会自动定位到知识点对应时间点，截取板书、公式、图表等关键画面。

通俗解释与考点：每个重点知识配有通俗类比解释，笔记附考点清单、名词解释与优质课程延伸链接。

备考规划（可选）：整理完成后可基于笔记生成艾宾浩斯复习时间表与考点优先级矩阵，按需开启。

隐私与数据 ▾

本页面为纯本地应用：所有数据保存在浏览器 localStorage 中，不上传、不联网、不追踪。清除浏览器数据会同时清空平台记录，可在「设置」里先导出备份。
